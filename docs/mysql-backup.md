# MySQL Database Backup

## Objective

Create a backup of the `IT_Support` MySQL database using `mysqldump`.

## 1. Create Backup File

Create the backup file:

```bash
touch IT_Support_Backup.sql

2. Take MySQL Database Backup

Run:

mysqldump -u root -p IT_Support > /root/IT_Support_Backup.sql

Enter the MySQL password when prompted.

The backup file is saved at:

/root/IT_Support_Backup.sql
3. Verify Backup File

Check the backup file:

ls -l /root/IT_Support_Backup.sql
4. View Backup Content

Display the backup file:

cat /root/IT_Support_Backup.sql

Example:

-- MySQL dump 10.13  Distrib 8.0.46
--
-- Host: localhost
-- Database: IT_Support

The file contains SQL statements generated by mysqldump.

5. Backup Command Explanation
mysqldump -u root -p IT_Support > /root/IT_Support_Backup.sql
mysqldump → MySQL database backup utility
-u root → MySQL username
-p → Prompt for password
IT_Support → Database to back up
> → Redirects output to a file
/root/IT_Support_Backup.sql → Backup file location
Result

The IT_Support database was successfully backed up using mysqldump.

Backup file:

/root/IT_Support_Backup.sql
